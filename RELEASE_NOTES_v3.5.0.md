# EduLedger ERP — Release Notes v3.5.0

## Release Summary
Version **v3.5.0** introduces the dedicated **Course & Program Master** feature in System Settings, tabbed academic management, detailed program metadata (Department, Degree Awarded, Affiliation, Eligibility, Baseline Fee, Program Description), 1-click Program Details Viewer, clean row action buttons, bulk select all/deselect all toolbar, and automatic Course & Branch sync during Student Registration.

---

## What's New in v3.5.0

### 1. Dedicated Course & Program Master
- **Comprehensive Program Metadata**: Manage Course Code, Name, Category (UG/PG/Diploma/Doctorate), Department/Faculty, Duration (Years), Total Semesters, Degree Awarded, Board Affiliation/Approval, Eligibility Criteria, Baseline Annual Fee (₹), and Detailed Description/Syllabus Notes.
- **Tabbed Academic Manager**: Re-architected Academic Settings into an intuitive 3-tab layout:
  - **Tab 1: 🎓 Course Programs Master**
  - **Tab 2: 🌿 Specialization Branches**
  - **Tab 3: 📅 Academic Sessions**

### 2. Clean Row Actions & Bulk Selection Toolbar
- **Sleek Row Actions**: Table rows now feature clean, spacious `👁 Details` and `✏ Edit` buttons.
- **Bulk Selection Toolbar**:
  - **Select All / Deselect All**: Checkbox header and toolbar controls for 1-click multi-row selection.
  - **⚡ Mark Selected Active**: Bulk activate selected course programs or branches.
  - **⏸ Mark Selected Inactive**: Bulk deactivate selected course programs or branches.
  - **🗑 Delete Selected**: Bulk delete selected items with safety confirmation.

### 3. Tabbed Add/Edit Form & 1-Click Details Viewer
- **3-Tab Form (`CourseDialog`)**: Organized into *Basic & Structure*, *Accreditation & Fee*, and *Overview & Notes*.
- **1-Click Details Viewer (`CourseDetailsDialog`)**: `👁 Details` button in Course Programs table for quick inspection of complete program specifications in a formatted card view.

### 4. Student Registration Auto-Sync
- **Auto-Ensure Master Registration**: Typing a custom or new course/branch name during student enrollment automatically registers it into the master database tables, updating all dropdowns and filter widgets across the application.
