# EduLedger ERP — Workspace Project Rules

## Release Folder Preservation Rule
> [!IMPORTANT]
> **NEVER delete or wipe any release version folder under the `release/` directory** (`release/v1.0.0`, `release/v1.0.1`, `release/v1.1.0`, `release/v1.2.0`, `release/v1.3.0`, etc.).
> All existing release version folders and their compiled binaries, packages, and reports must remain permanently preserved.
